# career-customGpt

## Objectives

The objectives of this project are:

1. **Explore Custom GPT design** through a practical multi-step workflow using specialized GPTs with clear responsibilities.
2. **Build a career documentation pipeline** for IT professionals and job seekers that converts interview-based career information into structured reusable knowledge.
3. **Generate and validate resumes** tailored to different roles using structured markdown as the source of truth.

---

## Workflow

```text
Custom GPT 1 → Career Extractor / Interviewer
        ↓
Custom GPT 2 → Markdown Structurer
        ↓
Custom GPT 3 → Resume Generator & Validator
```
